# GTM Creator Hub

Internal shortlist of creators for GTM outreach (GitHub Pages). **Multi-platform** (TikTok, Instagram, X, 抖音, 小红书) with **multi-tag** filtering (product, format, audience, geo, commerce).

**Dataset:** 17766 unique creators — TikTok 8946 · Instagram 4306 · X 562 · 抖音 2698 · 小红书 1254 (all `followers_num >= 1000`).
